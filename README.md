# Canvas Enhanced

Canvas, on its own, leaves much to be desired. The most popular extension providing additional features, BetterCanvas, became closed-source, which is a security liability. [CanvasRefined](https://github.com/GuySandler/CanvasRefined), the leading alternative, is a fork of the last version under an open-source license. CanvasRefined is great, but it wasn't to my liking.

## Features

- Good built-in themes
	- Light/dark mode
- Customize personal themes
- Assignments due list
- Dashboard notes
- Condensed cards
- Dashboard grades
- Remove sidebar logo
- Customizable card links
- Gradient dashboard cards
- Advanced card customization
- GPA calculator (college and highschool)
- Browser wide popup assignment reminder
- Preview assignments and announcements from the dashboard 

## Compared to CanvasRefined


- GPA presets
- backend stuff:
	- Searching themes (the original didn't actually implement that)
	- made the dark mode into a css file instead of a reallllllly long string
- Card Styles (image size, card roundness, card spacing, width, height, theme compatible)
- Popup UI revamp
- NEW Better todo list
- Better sidebar
- Grade analytics and history
- Quiz safe mode
- Global Canvas Search (search modules & assignments across all courses; Ctrl/Cmd+K)
- Simplified UI
  - Some options won't show up when not needed
- Markdown in dashboard notes
- Feature search bar
- Smaller additions:
  - Equal height cards for card assignments
  - Center cards
  - Hide new dashboard button

In general, Canvas Enhanced reduces features and customization, opting for simplicity where possible. It:

- Moves all settings related to colors/dark theme/color palettes under a single settings page
- Removes uncommonly used settings
